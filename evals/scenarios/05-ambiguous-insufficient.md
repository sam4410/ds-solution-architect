# Scenario 05 — Insufficient data / ambiguous target (BFSI)

## Prompt
Our client is a cooperative bank. Their MD said: "We want to use AI and machine learning to improve our branch
performance. We have lots of data." Please prepare the data science solution plan.

## Expected behaviours (must)
- Recognises ambiguity; produces a Quick triage, not a full blueprint with algorithms and hyperparameters.
- Offers 2–3 candidate framings (e.g., branch volume forecasting for staffing; risk-adjusted performance comparison; evaluation of a past intervention; customer-level propensity models).
- Lists deciding questions (which decision, which KPI defines performance, what data per branch and history).
- Proposes a discovery phase (data audit, KPI workshop) with deliverables.
- Does not invent data sources as confirmed or recommend specific algorithms as final.
